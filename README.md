# 📊 HR Analytics Dashboard | Power BI

## 📌 Project Overview

The **HR Analytics Dashboard** is an interactive data visualization project built using **Microsoft Power BI** to analyze workforce data and key Human Resources (HR) metrics.

This dashboard helps HR professionals monitor employee-related KPIs, explore workforce trends, and gain meaningful insights to support data-driven decision-making.

## 🛠️ Tools & Technologies

- 📊 **Microsoft Power BI** – Dashboard development and data visualization
- 🧮 **DAX** – Measures, calculations, and KPI analysis
- 🔄 **Power Query** – Data cleaning and transformation
- 📈 **Data Visualization** – Interactive charts, graphs, and reports

## ✨ Key Features

- 🎯 **HR KPI Monitoring** – Track key workforce metrics.
- 👥 **Employee Data Analysis** – Explore employee-related information.
- 🔍 **Interactive Filters & Slicers** – Analyze data dynamically.
- 📊 **Workforce Insights** – Visualize HR trends and patterns.
- 📉 **Data-Driven Analysis** – Support informed HR decision-making.

## 📁 Project File

📄 `HR Analytics Dashboard.pbix`

The Power BI file contains the dashboard and its interactive visualizations.

## 🚀 How to Use

1. 📥 Download the `HR Analytics Dashboard.pbix` file from this repository.
2. 💻 Open the file using **Microsoft Power BI Desktop**.
3. 🔎 Explore the visualizations, filters, and slicers.
4. 📊 Analyze the available HR metrics and workforce insights.
